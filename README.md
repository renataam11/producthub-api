# ProductHub API

RESTful API for product and inventory management, built with Python and FastAPI, tested with Postman, and managed using Scrum.

## Project Overview

ProductHub is a backend development project designed to practice REST API development, automated API testing, and agile software development methodologies.

## Tech Stack

- Python
- FastAPI
- Postman
- SQLite
- Git & GitHub
- Jira (Scrum)

## Project Status

Sprint 0 — Project Setup

## Features (Planned)

- Product CRUD operations
- Inventory management
- Database integration
- API validation and error handling
- Automated API testing with Postman
